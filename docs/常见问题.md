# 常见问题

排错用的。参数含义和上线节奏在[使用指南](使用指南.md)，改代码看[开发说明](开发说明.md)。

排查顺序建议：**先看体检，再看健康检查，再看日志**。

```
scripts\doctor.bat                          环境、依赖、配置、权限、端口
python -X utf8 wxbridge\ctl.py status       谁在跑
curl http://127.0.0.1:8766/api/health       现在能不能回，差在哪（控制台首页也显示）
控制台「日志」页 / wxbridge\bridge.out.log  通道原文
```

健康检查会把「微信 / 读消息 / 白名单 / 回复大脑 / 发消息」五项逐条给出结论和补救提示，绝大多数「为什么不回」到这里就有答案。

## 完全不回

| 症状 | 原因 | 怎么办 |
| --- | --- | --- |
| 健康检查里「白名单：空名单，谁都不回」 | 名单没加人 | 控制台「名单」页加，名字必须和微信里显示的一模一样（好友有备注就写备注） |
| 「读消息：还没解密出来」 | 首次要从微信进程抠密钥，十几秒；或权限不够 | 等 30 秒；用 `start_admin.bat` |
| 「回复大脑：模型没配好」 | `llm.baseURL` / `model` 空，或密钥不对 | 改 `config.yaml` 后 `restart.bat`，或控制台「设置」页改并点测试 |
| 「发消息：还没挂上微信窗口」 | 非管理员，UIA 树起不来 | `start_admin.bat`；微信窗口保持可见、别最小化 |
| 全绿但还是不回 | 群消息没 @ 你，或今天条数到上限，或消息太老 | 见下几条 |

## 某一个人不回

先想一个可能：**这个名字已经不是它了**。群改名、你改了备注，名单里那条就失效了 —— 去名单页核对，或直接删了重加。

其他原因：这个人被关掉了（名单页开关）；`respond.allowGroups: false` 时群一律不回；群里没 @ 你（`groupsNeedAt: true`，这是默认，也是应该的）；`minIntervalSeconds` 还没到；`dailyMaxPerChat` / `dailyMaxTotal` 到顶了。

日志里会写 `未回 [会话]：原因`，控制台「最近异常」也列了出来。

## 图片、语音、红包那类消息不回

后端会先把消息按类型分流。**动画表情**和**引用（回复某条）**会先翻成人话再进大脑 —— 表情变成 `[表情]`，引用变成「对方说的话（他引用了「被引用原文」）」，所以这两类是照样回的。

不回的是：图片、语音、视频、红包、链接、小程序、名片。原因是本地消息库里这些条目只有一串资源密钥和下载地址，没有可读正文（图片要另外下载解密、语音是音频文件），硬交给大脑只会编出莫名其妙的话。要支持它们得先接对应的解码/转写能力，属于新功能而不是配置项 —— 入口在 `wxbridge/backends/wechatauto.py` 的 `RICH_TYPES` 与它的解析函数。

## 控制台「测试连接」失败

「设置」页的「测试连接」是按**四个框里当前填的值**真发一条消息出去，不用先点保存 —— 所以它测的一定是你刚改的那组；反过来，改完忘了保存，测通了实际跑的却还是旧配置。

它只发到模型服务那一层，不碰微信：测通 = 地址、模型名、密钥都对，微信那边能不能发是另一回事（看健康检查另外几项）。

对号入座：

| 它说的话 | 真正的原因 | 怎么办 |
| --- | --- | --- |
| 「还缺模型服务地址（baseURL）」/「还缺模型名（model）」 | 有框空着 | 两个都填上。地址和模型名必须成套，拿 A 家的地址问 B 家的模型只会得到 401 或「模型不存在」 |
| 「模型名不对，服务里没有这个模型」 | 模型名写错 | 用服务商 / Ollama 界面里列出的原名，大小写、`:tag` 都要一致（`ollama list` 看） |
| 「密钥被拒（401/403）」 | 密钥错 / 过期 / 用错了家的密钥 | 重填，别带引号和空格；本地服务出现这条说明地址被判成云端了，检查 baseURL |
| 「地址打不到（404），实际打的是 …」 | 地址填错层，或粘成了整条 endpoint | 报错里那条 URL 就是真正打出去的，照着它改：OpenAI 兼容填到 `/v1` 为止，Anthropic 填根地址（`/v1/chat/completions`、`/v1/messages` 这类尾巴代码会自动剥，别的剥不掉） |
| 「连不上 …」 | 服务压根没开 / 端口错 / 地址不是本机 | 先把 Ollama、LM Studio 之类启动起来，端口对上；`127.0.0.1` 只在本机有效，服务在另一台机器上就填它的局域网 IP（`192.168.x.x`），这种地址同样不用填密钥 |
| 「这个域名解析不了」 | 漏了 `http://` / `https://`，或域名写错 | 补上协议头再看 |
| 「等了 N 秒还没回」 | 本地大模型第一次加载很慢，或机器扛不动 | 再点一次试试（第一次常要一两分钟）；还不行换小一点的模型 |
| 「HTTPS 证书校验没过」 | 走了代理 / 自签证书 | 换成服务自己的直连地址 |

健康检查里「回复大脑：模型没配好」是同一套判断，只是它不真发消息：**本地 / 局域网地址没密钥也算配好**，云端地址必须填密钥。

## 模型回了个空 / 「大脑没给出答案：无返回」

带「思考」的推理模型会把输出额度花在思考上，正文一个字都没有。`brain.py` 的 `MAX_OUTPUT_TOKENS` 现在是 8000，一般够；换成很啰嗦的推理模型仍可能踩到。

现象是：日志有请求、没正文、微信那边一条没发。补救：换指令型模型（如各家 `-chat` / `-instruct` 版），或把 `MAX_OUTPUT_TOKENS` 再放大，或超时后让本地大脑重试一次并附「别想太多，一句 10 字内」。

## 回复太慢 / 卡了三十几秒才发

正常的两层等待：`send.delaySeconds` 的随机延迟（默认 3~8 秒），加上发送库的拟人节流 —— 2 分钟内写满 6 次就强制冷却（默认 30 秒，`send.cooloffSeconds` 可调，计数存在用户目录 `rhythm.json`，重启不清零）。

调试时想跳过界面操作，用假后端跑链路：`scripts\demo.bat`。

## 同一条消息回了两遍

最常见是**跑了两套桥接**（比如老的还在跑又启动一次），两边都抢到同一条。

```
netstat -ano | findstr :8765
scripts\stop.bat            # 会连进程管家一起退
```

待补发队列的自动补发有 `already_delivered` 查重（先回读消息库，确实发过了就不再发）。如果你手动改过这块，务必保留这个查重。

## 端口被占 / 启动失败

`8765` 通道、`8766` 控制台、`8767` 管家。`doctor.bat` 会逐个报「空闲 / 被占」。被占就 `ctl.py stop`；顽固残留用任务管理器看那个 PID 是不是别的 `python.exe`。

临时换个端口联调：`python -X utf8 wxbridge\bridge.py --backend mock --demo --port 9765`。

## 改了配置没生效

`limits` / `send` / `respond` 是热重载，存盘就生效。`llm` / `persona` 要 `restart.bat`。另外注意：你在控制台改过「风格」或「设置」页里的模型，那 `style.json` / `brain.json` 会盖住 `config.yaml` 里的 `persona` / `llm` —— 想回文件说话就删掉对应 JSON。

## 终端里中文全是乱码

Windows 控制台默认代码页是 936（GBK），而程序要用 UTF-8 读写配置和日志，两边撞了就是乱码。`scripts\*.bat` 里已经处理好了：`chcp 936` + `set PYTHONIOENCODING=gbk` + `python -X utf8 -u`（文件照样 UTF-8，屏幕走 GBK）。

自己敲命令时照这套来就不会花屏：

```
set PYTHONIOENCODING=gbk
python -X utf8 -u wxbridge\ctl.py doctor
```

只在 git-bash / Windows Terminal 这类 UTF-8 终端里，才可以省掉 `PYTHONIOENCODING=gbk`。乱码只是显示问题，不影响功能。

## 微信自动更新之后失效了

微信大版本更新可能改变界面结构或让 UIA 树不再可用（本项目需要以管理员权限往 `Weixin.dll` 写一个激活字节，UIA 树才出现）。判断是哪一层坏了：先跑 `demo.bat`（不碰微信），如果链路正常，就说明是微信侧变了。此时先别硬发 —— 停掉自动回复，等后端适配。

## 想手动补一句 / 验证有没有真送达

```
# 手动发一条：先给「文件传输助手」试一遍中文编码，再发给真人
python -X utf8 wxbridge\tools\send_once.py 文件传输助手 测试一下中文
python -X utf8 wxbridge\tools\send_once.py 小王 刚在忙，打字说吧

# 回读消息库，看真正发出去的正文长什么样（可传多个会话名）
python -X utf8 wxbridge\tools\check_sent.py 小王 小明

# 按一段原文定位它到底落在哪个会话里（防发错窗口）
python -X utf8 wxbridge\tools\who_said.py 在呢在呢
```

`send_once.py` 是临时挂一个「不报身份」的应答端到 8765，只发 `send` 帧，不会跟自动回复抢活儿。

## 想彻底停

`scripts\panic.bat`（或 `Ctrl+Alt+X`）先刹车，再 `scripts\stop.bat` 退进程。`stop` 会连进程管家一起退 —— 只退桥接不管用，管家几秒后会把它拉起来。
